# پورتفولیو سجاد طوسی

## ساختار پروژه

```
project/
│
├── index.html              # صفحه اصلی
├── articles.html           # صفحه مقالات
├── web.html               # صفحه طراحی و توسعه وب
├── photo.html             # صفحه عکاسی و تصویربرداری
├── social.html            # صفحه مدیریت شبکه‌های اجتماعی
│
├── css/                   # فولدر استایل‌ها
│   ├── main.css          # استایل صفحه اصلی
│   └── pages.css         # استایل صفحات دیگر
│
├── js/                    # فولدر جاوااسکریپت‌ها
│   ├── main.js           # اسکریپت صفحه اصلی
│   └── pages.js          # اسکریپت صفحات دیگر
│
├── img/                   # فولدر تصاویر
│   └── ...
│
└── WebFonts/             # فولدر فونت‌ها
    └── fonts/
        ├── woff2/
        ├── woff/
        └── ttf/
```

## تغییرات اعمال شده

### 1. سازماندهی CSS
- تمام استایل‌ها از HTML جدا شده‌اند
- فایل `main.css` برای صفحه اصلی
- فایل `pages.css` برای صفحات articles, web, photo, social
- استایل‌های اینلاین به CSS خارجی منتقل شده‌اند

### 2. سازماندهی JavaScript
- کدهای جاوااسکریپت از HTML جدا شده‌اند
- فایل `main.js` برای صفحه اصلی
- فایل `pages.js` برای صفحات دیگر

### 3. مرتب‌سازی HTML
- کدهای HTML تمیز و خوانا شده‌اند
- استایل‌های اینلاین حذف شده‌اند
- کلاس‌های CSS برای المان‌ها اضافه شده‌اند

### 4. بهبود جداول قیمت‌گذاری
- جداول با کلاس‌های CSS استایل‌دهی شده‌اند
- استایل‌های اینلاین حذف شده‌اند
- جداول ریسپانسیو شده‌اند

## نحوه استفاده

1. فایل‌های فونت را در پوشه `WebFonts/fonts/` قرار دهید
2. تصاویر را در پوشه `img/` قرار دهید
3. فایل `index.html` را باز کنید
